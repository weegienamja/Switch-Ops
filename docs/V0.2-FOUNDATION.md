# SwitchOps v0.2 foundation

## Collection model

The dashboard performs one explicit refresh through one serialized SSH session. It runs the existing aggregate allowlisted command set, parses the outputs, then persists a snapshot. There is no timer, background poller, parallel switch access, or extra telemetry command. Telemetry retention defaults to 30 days and is configurable with `SWITCHOPS_TELEMETRY_RETENTION_DAYS`.

Mock and physical observations are namespaced so demonstrations cannot contaminate real device history or configuration baselines.

## Health semantics

Health has four inspectable states: `HEALTHY`, `NOTICE`, `ATTENTION`, and `CRITICAL`. Central thresholds are defined in `backend/app/health_logic.py`:

- CPU: notice at 65%, attention at 80%, critical at 95%.
- used memory: notice at 85%, attention at 90%, critical at 97%.
- new interface errors: notice at 1, attention at 10, critical at 100 per observation interval.

A non-zero cumulative error count does not create a current fault by itself. The first observation establishes a baseline; unchanged counters remain healthy. Increases, resets, and probable 32-bit wraps are represented explicitly. Stale log messages are not health inputs.

## Evidence and identity

The topology uses normalized device, interface, link, capability, observation, and event concepts. A learned MAC creates an observed endpoint. A meaningful interface description without discovery evidence creates an expected offline object. Classification progresses from unknown to category, vendor, and model only as evidence permits.

## Safety boundary

The Lab Guide accepts operation identifiers and validated interface filters, never command text. The dry-run planner performs three allowlisted show commands and returns `applyAvailable: false`; there is no apply API. Existing protected-interface and write-mode gates remain unchanged.

Raw configuration versions stay in private local storage. The UI receives only filenames, fingerprints, metadata, and redacted line diffs.

## Dependency decisions

SQLite, topology, vector visuals, explanations, and planning use existing platform libraries or project code. The only added packages are dev-only Vitest, jsdom, and React Testing Library for the requested frontend testing baseline. No graph framework, cloud service, AI runtime, image library, or polling package was added.

The isolated Paramiko legacy-SSH exception remains necessary for the IOS 12.2 device behind password authentication, pinned host keys, local-only networking, and process-local compatibility settings.
